## How To Install
1. Install system requirement like "Node.js, discord.js, git, MySql/MariaDB".
2. Make your program directory for workspace..=
3. Clone this repo ```git clone https://github.com/FianFi/Public-Spam-Guard```.
4. import file ```.sql``` to your database, or create it manual with table example on the sql file.
5. install nodemon for auto restart program if you save program file.
6. create ```.env``` file, example at [.env.example](.env.example).
7. run the file:\
    a.```npm run start```\
    b.```npm run dev``` Need Nodemon\
    c.```npm run deploy```\
